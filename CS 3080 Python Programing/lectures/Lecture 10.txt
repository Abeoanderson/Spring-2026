Protocols for networking
    TCP (Transmission Control Protocol) – Reliable, connection-oriented, ordered data (web, email, file transfer)
    UDP (User Datagram Protocol) – Unreliable, connectionless, faster (live streaming, gaming)
    HTTP/HTTPS – Web communication
    FTP – File transfer
    SMTP/POP3/IMAP – Email

socket is an endpoint for sending or reciving data accross a networking
    key socket functions
        socket() - create a socket
        bind() - bind to an address and port (server)
        listen() - listen for incoming connections (server)
        accept() - accept a connection (server)
        connect() connect to a server (client)
        send() / sendall() - send data
        recv() - recieve data 
        close() - close conneection
    
    socket called with socket.socket(socket.address family, socket.connection_type)
    family address:
        AF_INET - IPv4
        AF_INET6 - IPv6
        AF_UNIX - inter-process communication on same machine
    
    connection types:
        SOCK_STREAM - tcp
        SOCK_DGRAM - udp
        SOCK_RAW - raw, needs admin privledges
