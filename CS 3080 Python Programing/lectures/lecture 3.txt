super() = is a built in function that returns a proxy objet representing the parent class. it allows:
    call methods from parent class inside child class
    avoid explivitly naming th eparent class
    Easily extend or reuse the behavior of the parent class.

    we use super too:
        To call the parent class constructor and initialize the parent part of an object.
        To call overridden methods in the parent class while extending them in the child class.
        To make your code more maintainable and compatible with complex inheritance (multiple inheritance).
