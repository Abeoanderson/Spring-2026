in the collectsion module we have
    namedtuple:
        from collections import namedtuple
        Point = namedtuple('Point',[x,y])
        p = Point(1,2)
        print(p.x, p.y) # 1 2
    dequeue (double ended queue)
        same as a queue but can work form both sides
        deque() # Creates
        append() # addes to right side
        appendleft() # addes to left side
        pop() # pop right
        popleft() # pop left
    Counter() (dict subclass for counting hashable objects)
        c = Counter("banana")
        print(c) # Counter({'a': 3, 'n': 2, 'b': 1})   
        methods:
            .most_common(n) returns n most common elements
            .elemenets() iterate over elements with count
    OrderedDict
        dictionary that remembers insert order
            note this is obsolute after 3.7 because built in dict remmebers insertion order
    DefaultDict
        like a dictionary but with default key values if missing
    ChainMap
        combines multiple dictionaries into a single view

Intro to Machine Learning
    rule based AI

    WHy ML?
        Solves complex problems that traditional programing cannot
        Automate repetitive tasks with accuracy
        improves and adaps with futher use
        handels huge ammounts of data quickly
    Types of ML:
        supervised learning
            learning from labeled data
                for example sick or healthy patients
        unsupervised learning
            lerning form unlabeled data to deterimine trends
                for example group by age or gender
        reinforced learning
            learn though trial and error    
                for example identify fruit after correction
    ML has a few steps
        collect data
        clean data
        feed inputs
        check outputs
        correct and teach model
